# 20 Telegram-ботов-квизов (Marvel / DC / Аниме)

Готовый набор: **один код — 20 ботов**. Каждый бот — отдельный квиз по своей вселенной,
со своим рейтингом, статистикой, серией правильных ответов и кнопкой «поделиться».
Всё бесплатно: библиотека, токены и хостинг на Railway.

## Команды бота

- `/start` — приветствие и меню
- `/quiz` (или кнопка «🎮 Играть») — начать квиз
- `/top` (или «🏆 Рейтинг») — топ-10 игроков этого бота
- `/stats` (или «📊 Статистика») — очки, игры, лучшая серия, место
- `/help` — правила

## Быстрый старт (локально)

```bash
npm install
cp .env.example .env      # Windows: copy .env.example .env
# заполни токены (см. ниже)
npm start
```

Проверка без Telegram (мок-тесты):

```bash
npm test
```

## Шаг 1. Получить 20 токенов у @BotFather (бесплатно)

1. Открой Telegram → **@BotFather** → `/newbot`.
2. Придумай имя (например, `Marvel Quiz RU`) и username, **заканчивающийся на `bot`**
   (например, `marvel_quiz_ru_bot`).
3. BotFather пришлёт токен вида `123456789:AAH...` — вставь его в `.env`.
4. Повтори 20 раз (по одному боту на каждую вселенную).

> Совет: username'ы должны быть уникальными. Если занято — добавь `_ru`, `_quiz`, цифры.
> Никому не показывай токены — это полный доступ к боту.

`.env` выглядит так (по одной паре на бота):

```env
MARVEL_BOT_TOKEN=123456789:AAH...
MARVEL_BOT_USERNAME=marvel_quiz_ru_bot
DC_BOT_TOKEN=987654321:AAH...
DC_BOT_USERNAME=dc_quiz_ru_bot
```

`*_USERNAME` нужен только для кнопки «Поделиться» — можно оставить пустым.

## Шаг 2. Деплой на Railway (бесплатно)

1. Залей проект в GitHub (`.env` в репозиторий **не** попадает — он в `.gitignore`).
2. [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub repo** → выбери репозиторий.
3. В сервисе → **Variables** → добавь все `*_TOKEN` и `*_USERNAME` из `.env`
   (кнопка «Raw Editor» — можно вставить содержимое `.env` целиком).
4. Railway сам выполнит `npm install` и `npm start` (конфиг уже в `railway.json`).
5. В логах увидишь: `🚀 Запускаю ботов: 20 из 20` и строки `[ok] ... запущен`.

**Важно про хостинг:**

- Railway free-trial даёт ограниченные часы — 20 ботов в одном процессе это **один** сервис,
  поэтому расход минимальный. Следи за лимитом в **Usage**.
- Long-polling (без вебхуков) не требует публичного URL и порта — идеально для бесплатных тарифов.
- Альтернативы, если Railway не подходит: **Koyeb** (бесплатный инстанс), **Render**
  (free web service засыпает — для polling это плохо), **свой ПК/VPS** (`npm start`, не выключать).

### Обновить один бот

```bash
npm run bot -- marvel          # только Marvel
npm run bot -- marvel,dc,anime # несколько
```

Или в Railway: **Variables** → `ONLY_BOTS=marvel,anime`.

## Структура проекта

```
packs/            20 JSON-квизов + index.js (автозагрузка)
src/engine.js     логика квиза, кнопки, рейтинг
src/storage.js    JSON-хранилище игроков (state/<pack>.json)
src/leaderboard.js рейтинг и место игрока
src/index.js      запуск всех ботов
src/run-one.js    запуск выбранных ботов
scripts/          validate / smoke / simulate (тесты без Telegram)
```

### Как добавить свой квиз

1. Создай `packs/mytopic.json` по образцу любого пака:
   `key`, `title`, `emoji`, `tagline`, `greeting`, 5 `ranks`, 12 `questions`
   (в каждом `q`, `options`, `answer`, `fact`).
2. Добавь строку в `src/bots.js`:
   `{ id: 'mytopic', env: 'MYTOPIC_BOT_TOKEN' }`
3. Добавь токен в `.env` и запусти.

Валидатор подскажет, если ответ не совпадает ни с одним вариантом:

```bash
npm run validate
```

## Как на этом заработать (без вложений)

Боты бесплатны для игроков — зарабатывать можно на внимании:

1. **Реклама в фактах.** В поле `fact` можно добавить строку с партнёрской ссылкой
   (казино/аниме-магазины не бери — забанят; лучше легальные: книги, мерч, курсы).
2. **Партнёрские ссылки на аниме-сервисы и магазины мерча** — вставляй в `/start`-приветствие
   или в финальный экран (там уже есть кнопка «Поделиться» — рядом можно добавить вторую).
3. **Рост аудитории → продажа рекламы.** Когда у ботов суммарно тысячи активных игроков,
   рекламодатели платят за посты/рассылки. Кнопка «Поделиться» — твой бесплатный канал роста.
4. **Донаты.** В финал добавь ссылку на донат (Boosty / DonationAlerts) —
   «понравилось? угости разработчика».
5. **Платный контент.** Бесплатные 12 вопросов, а «продвинутый пак» (ещё 20 вопросов,
   режим на время, дуэли) — за звёзды Telegram или подписку в закрытом канале.
6. **Свои боты под заказ.** Этот код — готовый шаблон: делай квизы для брендов,
   школ, магазинов за деньги.

Реалистично: доход появляется с трафика. Сначала — контент и подписчики,
монетизация — вторым шагом. Не покупай рекламу, пока не проверишь удержание
(сколько людей доигрывает до финала — это видно по `/stats` и по числу `games`).

## Лицензия и правовые мелочи

- Код — твой, используй как хочешь.
- Названия вселенных, персонажи и логотипы принадлежат правообладателям.
  Для бесплатного фан-проекта это обычная практика, но **не продавай мерч с их IP**
  и не выдавай ботов за официальные — добавь в описание бота «фанатский квиз».
- Токены и персональные данные игроков (id, username) храни только у себя;
  не публикуй `state/*.json`.

## Диагностика

| Симптом | Причина / решение |
|---------|-------------------|
| `Ни одного токена в .env` | Нет файла `.env` или токены не заполнены |
| `нет токена для: ...` | Забыл конкретный `*_TOKEN` |
| `409 Conflict` в логах | Тот же токен запущен дважды (второй процесс/старый деплой) |
| Бот молчит | Проверь токен у BotFather, перезапусти сервис |
| Рейтинг пуст | Игроки ещё не доиграли квиз до конца |
